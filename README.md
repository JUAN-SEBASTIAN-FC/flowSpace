FlowSpace is a meticulously crafted frontend application prioritizing UI/UX, responsive design, and professional visual aesthetics. It draws inspiration from industry-leading products like Stripe, Linear, Vercel, and Notion, ensuring a premium feel out of the box.

## 🚀 Features

- **Premium UI/UX:** Sophisticated, minimalist, and clean design system.
- **Fully Responsive:** Adapts flawlessly to Desktop (1920px+), Laptop (1440px), Tablet (768px+), and Mobile (320px+).
- **Modern Tech Stack:** Powered by **React 19**, **Vite 8**, and **Tailwind CSS v4**.
- **Micro-interactions & Animations:** Smooth hover states, transitions, and accessible visual feedback.
- **Consistent Design Language:** Standardized typography, spacing, shadows, and color palette.
- **Accessible:** High contrast, clear focus states, and keyboard-navigable components.

## 🛠️ Tech Stack

- **Core:** [React 19](https://react.dev/) + [Vite 8](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Charts:** [Recharts](https://recharts.org/)
- **Routing:** [React Router v7](https://reactrouter.com/)
- **Toast Notifications:** [React Hot Toast](https://react-hot-toast.com/)
- **Date Utils:** [date-fns](https://date-fns.org/)

## 📦 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18+ recommended) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/flowspace.git
   cd flowspace
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 🎨 Design Philosophy

This project strictly adheres to a premium design philosophy:
- **Flawless Responsiveness:** Flexbox and CSS Grid are used to ensure fluid adaptation across all breakpoints. No horizontal scrolling, no overlapping elements.
- **Balanced Spacing:** Utilizing a strict spacing scale (`4px`, `8px`, `16px`, `24px`, etc.) for a harmonious and breathable visual rhythm.
- **Elegant Depth:** Subtle glassmorphism, refined multi-layered shadows, and sophisticated micro-animations elevate the overall user experience without feeling cluttered.
- **Clear Typography:** Professional font hierarchies emphasizing legibility and contrast.
